# AwesomeWin3x
List of projects that work on Windows 3.11 / 3.1 / 3.0 / 3.x / 3.1x and Win32s
==
Recently thanks to determined developers with free time and AI coders, there have been huge emergence of projects that backport or create new software for Windows 3.x which previously was thought to not be possible.
I decided to compile list of such software so you can find such much smoothly.
* Windows 3.1 Multimedia Codec Pack(https://github.com/Toyoyo/win31-codecs) - brings MPEG-1, MPEG-4, Ogg Opus, Ogg Vorbis into Windows 3.1x. For some parts Win32s required.
* PuTTY Win32s 0.85(https://github.com/Toyoyo/putty-win32s) - brings PuTTY into Win32s
* W3VN - STVN Win32s Port(https://github.com/Toyoyo/w3vn) - visual novel engine from Atari ST for Win32s
* VSBHDA(https://github.com/Toyoyo/VSBHDA-w31) - Sound Blaster emulation for Windows 3.1x for HD Audio hardware
* irssi(https://github.com/Toyoyo/irssi-win32s) - port of irssi 1.4.5 to Windows 3.1 via Win32s with TLS 1.3
* W3MikMod(https://github.com/Toyoyo/w3mikmod) - Win32 GUI for MilkMod for Win32s
* win31c CAD(https://github.com/CalculatedCausality/win31c-inventor) - inventor-style CAD for Windows 3.1 Win16
* VGESVGA(https://github.com/PluMGMK/vbesvga.drv) - True Color video driver for Windows 3.x that can do up to Full HD resolution
* VNUMERRD386(WIP)(https://github.com/PluMGMK/vnumerrd.386) - Improved FPU exception handling on Windows 3.x for Haswell and newer CPUs
* AHCIFIX386(https://github.com/PluMGMK/ahcifix.386) - VxD to allow Windows 3.1 Enhanced Mode to be used with Intel AHCI SATA controllers
* S3Wide(https://github.com/Magneticon/S3Wide) - Windows 3.1x display driver that targets native Widescreen modes for S3 Trio64 emulated by DosBox-X
* 86TO88 aka WM88 Bridge(https://github.com/astrobleem/86TO88) - Translation layer that makes Windows 3.1 unmodified Minesweeper executable work on Windows 3.0 Real Mode
* W16 for ELKS(https://github.com/astrobleem/elks-w16) - Win16 compatability layer for ELKS(16-bit Linux). Essentially its 16-bit Wine for ELKS
* Windows 3.0 color CGA(https://github.com/astrobleem/windows-3-cga) - 160x100 CGA driver for Windows 3.0.
* Win16 Web Stack Porting Library Collection(https://github.com/qv1145145/Win16WebStack) - Win16 port of several opensource projects for Windows 3.11, such as duktape, libCSS, Gumbo-parser, FreeType and more
* Hotkey Manager for Windows 3.1(https://github.com/qv1145145/Hotkey-Manager-for-Windows-3.1)
* MCP-Win32s(https://github.com/connollydavid/MCP-Win32s) - Model Context Protocol server for Win32 systems which goal is to allow AI agents interact with any Win32-based system from Windows 3.1 with Win32s to Windows 11.
* 7-Zip 26.05 Legacy Port(https://github.com/ages2001/7zip2605) - modern 7-zip for Win16, Win32s and MS-DOS.
* RetroPlayer(https://github.com/ages2001/RetroPlayer) - modern codec player for legacy Windows from Windows 3.0 to 11 based on VLC 3.0.24 engine.
* WinUSB(https://github.com/ages2001/WINUSB) - USB, Thunderbolt for DOS, Windows 1.x, 2.x, 3.x and 9x
* WinUDF(https://github.com/ages2001/WINUDF) - UDF file system for DOS, Windows 1.x, 2.x, 3.x and 9x
* WinAudio(https://github.com/ages2001/WINAUDIO) - HD Audio, AC'97 for DOS, Windows 3.x, 9x
* WinDisk(https://github.com/ages2001/WINDISK) - IDE, SATA AHCI, NVMe, SD, eMMC driver for DOS, Windows 1.x, 2.x, 3.x, 9x
* OSFree Notepad(https://github.com/osfree-project/notepad)
* WinLlama-3.x(https://github.com/RetroGamer02/WinLlama-3.x) - Win16 client for Ollama server.
* WIN4XLDR(https://github.com/pufengdu/WIN3XLDR) - Windows 3.x loader for MS-DOS 7.10/8.0
